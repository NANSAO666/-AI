## ✨ 演示说明

- 这是一个**纯前端静态演示**：页面结构、导航、交互与真实系统一致，所有业务数据为内置示例数据。
- 底部绿色横幅标注「静态演示版」——演示版**不会真实保存数据**，刷新后恢复示例数据。
- 登录：点击右侧「演示账号」任意一个（如 **管理员 / admin**），**双击**即可直接进入系统；
  统一密码为 `goodjob123`。
- 支持按 业务员 / 主管 / 管理员 / 超级管理员 切换查看不同数据权限范围。

## 🚀 本地运行

```bash
# 方式一：任意静态服务器
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/

# 方式二：npx serve
npx serve .
```

## 📦 技术说明

- 前端基于 **Vite + TypeScript** 构建的原始单页原型（`index.html` + 打包 JS）。
- 演示版通过浏览器端 **Mock 层**（`goodjob-demo-mock.js`）拦截 `/api/*` 请求，
  返回内置示例数据，实现无后端运行。
- 真实系统需要 Node.js 后端 + MySQL 部署，源码见 [sendoh-huang/GoodJob](https://gitee.com/sendoh-huang/GoodJob)。
